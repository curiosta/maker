ESP32 Climate Node with OLED and MQTT Dashboard

  • beginner
  • 4-6 hours

Draft and unofficial, not affiliated with Fab Academy. Check prices, GST and parts before you buy.

Summary

A desk-sized weather/air node: ESP32 reads temperature, humidity and pressure, shows them on a 0.96" OLED and pushes JSON to an MQTT broker (public test broker or a local Mosquitto) with a simple browser dashboard. Optional laser-cut acrylic case.

What it teaches

Read digital (DHT22) and I2C (BMP280) sensors, share one I2C bus with an OLED (addressing 0x76 / 0x3C), then publish readings over Wi-Fi via MQTT to a live web dashboard. Good first project for input devices + networking weeks.

Topics it touches, in Fab Academy-style terms:

  • Input devices
  • Networking and communications
  • Embedded programming
  • Interface and application programming
  • Computer-controlled cutting (optional enclosure)
