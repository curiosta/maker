Wi-Fi Obstacle-Avoiding Mini Rover (Laser-Cut Chassis)

  • intermediate
  • 8-12 hours

Draft and unofficial, not affiliated with Fab Academy. Check prices, GST and parts before you buy.

Summary

Two-wheel + caster rover on a 3 mm MDF/acrylic chassis. ESP32 serves a phone-friendly control page (drive / auto-avoid) and uses a servo-mounted HC-SR04 to look left/right before turning.

What it teaches

Design a parametric laser-cut chassis around N20 motors, drive them with a DRV8833 H-bridge using PWM, add an ultrasonic scan head, handle a 2S battery with a 5V buck converter, and add a Wi-Fi web UI for manual/auto modes.

Topics it touches, in Fab Academy-style terms:

  • Mechanical design
  • Computer-controlled cutting
  • Output devices
  • Input devices
  • Embedded programming
  • Networking and communications
  • Machine design (intro)

Safety notes

  • 2x18650 in series = 7.4V (up to 8.4V charged). N20 6V motors: cap PWM duty at about 70-75% in firmware.
  • Set the MP1584 buck output to 5.0V with a multimeter BEFORE connecting the ESP32.
  • Charge cells outside the holder in a proper 18650 charger; use protected cells and never leave charging unattended.
