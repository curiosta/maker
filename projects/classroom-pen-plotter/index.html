Classroom Pen Plotter for Geometry and Art (Machine Design)

  • advanced
  • 20-30 hours over 1-2 weeks (group project)

SDG 4 · Quality Education

A shared open-hardware machine that lets learners turn coordinate geometry, code and art into drawings, built and repaired by the class.

Safety notes

  • Use only a certified external adapter; do not open, build or modify mains supplies.
  • Pinch points: keep fingers and hair away from belts and pulleys while powered; add an accessible power switch.
  • Stepper drivers and motors get hot; set driver current limits before first run.

Draft and unofficial, not affiliated with Fab Academy or the United Nations. Check prices, GST and parts before you buy.

Summary

An A4/A3 drawing machine with printed carriages and a laser-cut base. Students write programs that draw spirals, graphs and patterns, then see the maths on paper. Built as a team in machine design week.

What it teaches

Design a 2-axis gantry with 8 mm rods, LM8UU bearings and GT2 belts, size steps per mm, drive two Nema 17 motors through bipolar drivers, add a servo pen lift, and stream G-code from a simple web or Python interface.

Topics it touches, in Fab Academy-style terms:

  • Mechanical design
  • Machine design
  • Output devices
  • Embedded programming
  • 3D scanning and printing
  • Interface and application programming
